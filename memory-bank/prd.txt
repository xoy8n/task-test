# 📄 제품 요구사항 문서 (PRD)

## 1. 📌 프로젝트 명  
**AI 끝말잇기 게임**

---

## 2. 🎯 목적 및 목표  
- 사용자가 AI와 번갈아 가며 끝말잇기 게임을 즐길 수 있도록 한다.  
- 한글 단어를 기반으로 한 어휘력 향상과 재미 제공.  
- AI가 적절하고 자연스러운 단어를 제시하도록 구현.  

---

## 3. 👥 주요 사용자  
- 한글 어휘 게임을 좋아하는 일반 사용자  
- 학습 목적으로 끝말잇기를 이용하는 학생  

---

## 4. 📚 주요 기능 정의  

### 4.1. 게임 기능  
- **사용자 입력**: 단어를 입력하고 제출.  
- **AI 응답**: 끝말에 맞는 단어 자동 생성.  
- **단어 유효성 검사**:  
  - 국어사전 API 또는 내장 단어 리스트로 유효성 확인.  
  - 이미 사용된 단어는 사용 불가.  
- **게임 종료 조건**:  
  - 사용자가 잘못된 단어 입력 시.  
  - AI가 단어를 제시하지 못할 시.  

### 4.2. 추가 기능 (선택적)  
- 난이도 설정: 쉬움 / 보통 / 어려움 (AI의 응답 난이도 차이)  
- 타이머: 제한 시간 내 입력하도록 설정 (예: 10초)  
- 점수 시스템: 연속 성공 횟수에 따라 점수 부여  

### 4.3. 기술 스택  
- **프론트엔드**: React (또는 간단한 HTML + JS)  
- **백엔드**: Node.js (옵션, 단순 로컬 실행 시 생략 가능)  
- **AI 단어 추천**: 내장 단어 데이터 또는 ChatGPT API 활용  

### 4.4. 데이터  
- 한글 단어 리스트 (JSON 또는 DB 저장)  
- 사용된 단어 기록 (세션별 관리)  

---

## 5. 🧩 사용자 시나리오  
1. 사용자가 게임 시작 버튼 클릭.  
2. 사용자 단어 입력 (예: "바나나").  
3. AI가 "나"로 시작하는 단어 제시 (예: "나무").  
4. 사용자 "무"로 시작하는 단어 입력... 반복.  
5. 어느 한쪽이 단어를 내지 못하면 게임 종료 후 결과 표시.  

---

## 6. 📈 성공 지표 (KPI)  
- 사용자 평균 게임 지속 시간  
- 평균 입력 단어 수  
- 게임 종료 사유 (AI 승/사용자 승/무효)
