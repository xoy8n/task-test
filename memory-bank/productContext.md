# 📦 제품 컨텍스트 (Product Context)

## 1. 존재 이유 (Why this project exists)

많은 사람들이 간단하면서도 지적으로 자극이 되는 게임을 찾고 있습니다. 특히 한글 어휘력 향상에 관심 있는 사용자나 교육적 목적으로 즐길 수 있는 콘텐츠에 대한 수요가 있습니다. AI 끝말잇기 게임은 이러한 요구를 충족시키기 위해 존재합니다.

## 2. 해결하려는 문제 (Problems it solves)

- **지루함 해소**: 사용자에게 재미있고 중독성 있는 게임 경험을 제공합니다.
- **어휘력 증진**: 게임을 통해 자연스럽게 다양한 한글 단어를 접하고 학습할 기회를 제공합니다.
- **AI 기술 접목**: AI와의 상호작용을 통해 새로운 형태의 엔터테인먼트를 제공합니다.

## 3. 사용자 경험 목표 (User experience goals)

- **직관적인 사용성**: 누구나 쉽게 게임을 시작하고 즐길 수 있도록 단순하고 명확한 인터페이스를 제공합니다.
- **흥미로운 게임플레이**: AI가 적절한 난이도와 반응 속도로 단어를 제시하여 사용자의 몰입도를 높입니다.
- **성취감 제공**: 게임에서 승리하거나 어려운 단어를 성공적으로 이어갔을 때 성취감을 느낄 수 있도록 합니다.
- **교육적 가치**: 재미뿐만 아니라 어휘력 향상이라는 교육적 효과도 얻을 수 있도록 합니다.

## 4. 주요 사용자 (Target Users)

- 한글 어휘 게임을 좋아하는 일반 사용자
- 학습 목적으로 끝말잇기를 활용하고자 하는 학생
- 간단한 캐주얼 게임을 즐기는 사용자

## 5. 사용자 시나리오 (User Scenarios)

1. 사용자는 웹사이트에 접속합니다. (게임 시작 버튼은 별도로 없음)
2. 사용자가 첫 단어를 제시합니다.
3. 사용자는 끝말에 맞춰 다음 단어를 입력창에 입력하고 '제출' 버튼을 누릅니다.
4. 시스템은 단어의 유효성을 검사합니다 (이미 사용된 단어인지, 사전에 있는 단어인지 등).
5. 유효한 단어라면, AI는 해당 단어의 끝말에 맞춰 다음 단어를 제시합니다.
6. 사용자와 AI는 번갈아 가며 단어를 제시합니다.
7. 어느 한쪽이 유효한 단어를 제시하지 못하거나 제한 시간을 초과하면 게임이 종료됩니다.
8. 게임 종료 후, 결과(승/패, 점수 등)가 표시됩니다.
