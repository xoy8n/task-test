# 📝 프로젝트 개요 (Project Brief)

## 1. 프로젝트 명

**AI 끝말잇기 게임**

## 2. 프로젝트 목표

- 사용자가 AI와 즐겁게 끝말잇기 게임을 할 수 있는 환경 제공
- 한글 어휘력 향상 및 재미있는 학습 경험 제공
- AI가 상황에 맞는 자연스러운 단어를 제시하도록 구현

## 3. 주요 기능

- **게임 플레이**: 사용자 단어 입력 및 AI 응답 기능
- **단어 유효성 검사**: 국어사전 연동 또는 내장 리스트 활용, 중복 단어 방지
- **게임 종료 조건**: 잘못된 단어 입력 또는 AI 단어 제시 불가 시 게임 종료

## 4. 기술 스택 (예상)

- **프론트엔드**: React 또는 HTML/JS
- **백엔드**: Node.js (선택 사항)
- **AI 단어 추천**: 내장 단어 DB 또는 외부 API (예: ChatGPT)

## 5. 성공 지표

- 사용자 평균 게임 지속 시간
- 세션 당 평균 입력 단어 수
- 게임 결과 분포 (AI 승, 사용자 승 등)
