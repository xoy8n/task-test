- **사용자 첫 단어 제시 기능 구현 (`src/app/page.js`)**:
  - 게임 시작 시 `currentWord`, `gameMessage`, `history` 상태를 사용자가 첫 단어를 입력하도록 초기화.
  - `handleSubmit` 함수를 수정하여, 게임의 첫 턴에는 사용자가 입력한 단어를 첫 단어로 설정하고 AI에게 해당 단어의 마지막 글자로 시작하는 단어를 요청하도록 변경.
  - AI가 첫 단어에 대해 적절한 응답을 하지 못할 경우(중복, 길이, 규칙 위반 등) 사용자에게 알리고, 게임을 이어나갈 수 있도록 메시지 및 상태 처리.
