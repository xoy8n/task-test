# Overview
**제품명:** AI와 함께하는 끝말잇기

본 프로젝트는 사용자가 AI와 한국어 끝말잇기 게임을 즐길 수 있도록 하는 것을 목표로 합니다. Next.js와 Google Gemini-2.0-Flash 모델을 활용하여 싱글플레이 웹 애플리케이션을 개발합니다.

- **Problem it solves:** 사용자가 시간과 장소에 구애받지 않고 한국어 끝말잇기 게임을 통해 재미를 느끼고 어휘력을 향상할 수 있도록 합니다.
- **Who it's for:** 한국어 어휘 게임을 좋아하는 사용자, AI와 상호작용하는 게임에 관심 있는 사용자.
- **Why it's valuable:** Gemini-2.0-Flash의 Function Calling 기능을 활용하여 보다 자연스럽고 지능적인 AI 대결 상대를 제공하며, Next.js를 통해 반응성이 뛰어난 웹 환경을 제공합니다.
- **주요 기술 스택:**
  - Frontend: Next.js (App Router, React 18)
  - AI API: Google Gemini-2.0-Flash (Function Calling 사용)
  - 배포: 초기 로컬 테스트, 추후 Vercel 배포 예정

# Core Features

## 게임 시작
- **What it does:** 사용자가 '게임 시작' 버튼을 클릭하면 AI와의 끝말잇기 세션이 시작됩니다.
- **Why it's important:** 게임의 진입점으로, 사용자가 게임을 시작할 수 있는 명확한 방법을 제공합니다.
- **How it works at a high level:** 버튼 클릭 시 게임 상태가 초기화되고, AI 또는 사용자가 첫 단어를 제시할 준비를 합니다.

## 단어 입력
- **What it does:** 사용자가 텍스트 필드에 단어를 입력하고 제출합니다.
- **Why it's important:** 사용자가 게임에 참여하는 주요 수단입니다.
- **How it works at a high level:** 입력된 텍스트는 유효성 검증을 거친 후 게임 로직에 따라 처리됩니다.

## AI 응답
- **What it does:** 사용자가 제시한 단어에 이어 Gemini-2.0-Flash API의 Function Calling을 사용하여 AI가 다음 단어를 제시합니다.
- **Why it's important:** 게임의 핵심 상호작용으로, AI가 사용자의 상대 역할을 수행합니다.
- **How it works at a high level:** 사용자의 마지막 단어를 Gemini API에 전달하고, 정의된 함수(예: `get_next_korean_word`)를 통해 다음 단어를 받아옵니다.

## 단어 검증 (사용자)
- **What it does:** 사용자가 입력한 단어가 유효한지 검증합니다 (예: 실제 존재하는 단어인지, 끝말잇기 규칙에 맞는지).
- **Why it's important:** 게임의 공정성과 규칙 준수를 보장합니다.
- **How it works at a high level:** 간단한 내장 단어 리스트나 외부 사전 API를 통해 단어를 검증합니다. (초기 MVP에서는 생략 가능)

## AI 단어 검증 (옵션)
- **What it does:** AI가 제시한 단어의 유효성을 검증합니다.
- **Why it's important:** AI 응답의 품질을 보장하고, AI가 규칙을 어기는 것을 방지합니다.
- **How it works at a high level:** 사용자 단어 검증과 유사한 방식으로 AI가 제시한 단어를 검증합니다.

## 게임 종료
- **What it does:** 어느 한쪽이 패배 조건(예: 유효한 단어를 제시하지 못함)을 충족하면 게임이 종료되고 결과가 표시됩니다.
- **Why it's important:** 게임의 명확한 결말과 승패를 제공합니다.
- **How it works at a high level:** 단어 검증 실패 또는 AI 응답 불가 시 게임 상태가 '종료'로 변경되고, 승리/패배 메시지가 표시됩니다.

## 리셋
- **What it does:** 사용자가 게임을 초기화하고 다시 시작할 수 있게 합니다.
- **Why it's important:** 사용자에게 게임을 반복해서 즐길 기회를 제공합니다.
- **How it works at a high level:** '재시작' 버튼 클릭 시 모든 게임 상태(사용된 단어, 현재 단어 등)가 초기화됩니다.

## 유저 인터페이스 (UI) 요소
- 단어 입력창
- AI 응답 출력 영역
- 현재 단어 표시 (누구의 턴인지, 마지막 단어 등)
- 게임 상태(진행 중, 사용자 승리, AI 승리) 표시
- 게임 시작/재시작 버튼

# User Experience

## User personas
- **캐주얼 게이머:** 간단하고 재미있는 한국어 게임을 찾는 사용자.
- **AI 기술 관심 사용자:** 최신 AI 기술(Gemini)과 상호작용하는 경험을 원하는 사용자.
- **어휘 학습자:** 놀이를 통해 한국어 어휘를 연습하고 싶은 학생 또는 성인.

## Key user flows
1.  사용자가 웹 애플리케이션에 접속합니다.
2.  '게임 시작' 버튼을 클릭하여 게임을 시작합니다.
3.  (선택적: AI 또는 사용자가 첫 단어 제시)
4.  사용자는 제시된 단어의 마지막 글자로 시작하는 단어를 입력창에 입력하고 제출합니다.
5.  시스템은 사용자 단어를 검증하고, 유효하면 AI에게 다음 단어를 요청합니다.
6.  AI가 Function Calling을 통해 다음 단어를 제시하고, 화면에 표시됩니다.
7.  4~6단계가 반복됩니다.
8.  사용자 또는 AI가 유효한 단어를 제시하지 못하면 게임이 종료되고 결과(승/패)가 표시됩니다.
9.  사용자는 '재시작' 버튼을 눌러 새 게임을 시작할 수 있습니다.

## UI/UX considerations
-   **직관성:** 사용자가 별도의 설명 없이도 게임 방법과 UI 요소를 쉽게 이해하고 사용할 수 있어야 합니다.
-   **피드백:** 사용자 입력, AI 응답, 단어 검증 결과, 게임 상태 변경 등 모든 상호작용에 대해 명확하고 즉각적인 시각적 피드백을 제공해야 합니다.
-   **반응성:** AI 응답 대기 시간 등 비동기 처리 중에는 로딩 상태를 명확히 표시하여 사용자가 시스템이 작동 중임을 알 수 있도록 합니다.
-   **오류 처리:** API 호출 실패, 잘못된 사용자 입력, AI의 예외적인 응답 등에 대해 사용자에게 친화적인 오류 메시지를 보여주고, 게임이 비정상적으로 종료되지 않도록 합니다.
-   **일관성:** 전체 애플리케이션에서 디자인, 용어, 인터랙션 패턴 등을 일관되게 유지합니다.

# Technical Architecture

## System components
-   **Frontend:** Next.js (App Router, React 18)를 사용하여 사용자 인터페이스 및 클라이언트 사이드 로직을 개발합니다.
-   **AI API:** Google Gemini-2.0-Flash 모델을 사용하며, 특히 Function Calling 기능을 활용하여 AI의 단어 추천 로직을 구현합니다.

## Data models
-   **Current Word:** 현재 게임에서 마지막으로 제시된 단어 (문자열).
-   **Used Words List:** 현재 게임 세션에서 이미 사용된 단어들의 목록 (문자열 배열) - 중복 방지용.
-   **Game State:** 게임의 현재 상태 (예: 'idle', 'user_turn', 'ai_turn', 'user_win', 'ai_win').
-   **(선택적) Korean Word List:** 단어 유효성 검증을 위한 간단한 한국어 단어 목록 (JSON 파일 또는 인메모리 배열).

## APIs and integrations
-   **Google Gemini API:** 핵심 AI 로직 처리를 위해 사용됩니다. Function Calling을 통해 `get_next_korean_word`와 같은 함수를 호출하여 AI의 응답을 받습니다.
-   **(선택적) 외부 한국어 사전 API:** 보다 정확한 단어 유효성 검증을 위해 연동될 수 있습니다.

## Infrastructure requirements
-   **API Key Management:** 프론트엔드에서 Google Gemini API를 직접 호출할 경우 API 키 노출 위험이 있으므로, 이를 보호하기 위해 Proxy 서버(예: Next.js API Routes) 또는 Vercel Edge Function과 같은 서버리스 함수를 활용하는 것을 고려합니다.
-   **Deployment:** 초기 개발 및 테스트는 로컬 환경에서 진행하며, 최종 배포는 Vercel 플랫폼을 고려합니다.

# Development Roadmap

## MVP requirements (Phase 1-5 from original PRD)
1.  **Next.js 프로젝트 세팅:** App Router, TypeScript 적용하여 기본 프로젝트 구조를 설정합니다.
2.  **기본 UI 구성:** 게임 화면 레이아웃, 단어 입력창, AI 응답 표시 영역, 현재 단어 및 게임 상태 표시, 게임 시작/재시작 버튼 등 기본적인 UI 요소를 구현합니다.
3.  **Gemini API Function Calling 연동:** `get_next_korean_word` 함수를 정의하고, 사용자의 마지막 단어를 입력으로 받아 AI가 다음 단어를 추천하도록 Gemini API와 연동합니다. (초기에는 API 키를 클라이언트에서 직접 사용하되, 보안 경고와 함께 추후 개선 명시)
4.  **게임 흐름 컨트롤 구현:** 사용자와 AI가 번갈아 단어를 제시하는 기본 게임 루프, 턴 관리, 게임 시작/종료 로직(간단한 조건)을 구현합니다.
5.  **단어 검증 로직 (최소 기능):** 사용된 단어 목록을 기반으로 중복 단어 사용을 방지하는 로직을 우선 구현합니다. (사전 존재 여부 검증은 MVP 이후로 연기 가능)

## Future enhancements (Phase 6-7 and other considerations from original PRD)
-   **단어 유효성 검증 강화:** 간단한 내장 단어 리스트를 활용하거나 외부 한국어 사전 API를 연동하여 사용자와 AI가 제시하는 단어의 실제 존재 여부 및 품사(명사만 허용 등)를 검증합니다.
-   **API Key 보안 강화:** Proxy 서버 또는 Vercel Edge Function을 구현하여 API 키를 안전하게 관리합니다.
-   **로딩 상태 및 에러 핸들링 개선:** AI 응답 대기 중 로딩 인디케이터 표시, API 호출 실패 또는 잘못된 입력에 대한 사용자 친화적 오류 메시지 및 graceful degradation 처리를 구현합니다.
-   **UI/UX 개선:** 사용자 피드백을 반영하여 게임의 재미와 사용성을 지속적으로 개선합니다. (애니메이션, 효과음 등 추가 고려)
-   **Vercel 배포 준비 및 실행:** 애플리케이션을 Vercel에 배포하여 웹에서 접근 가능하도록 합니다.

# Logical Dependency Chain
1.  **프로젝트 설정 (Next.js):** 가장 먼저 개발 환경을 구축합니다.
2.  **기본 UI 뼈대 구현:** 사용자와 상호작용할 화면의 기본 구조를 만듭니다.
3.  **Gemini API 연동 (Function Calling):** AI의 핵심 응답 로직을 구현합니다. 이것이 없으면 게임 진행이 불가능합니다.
4.  **기본 게임 흐름 제어:** 사용자 턴과 AI 턴을 관리하고, 게임 시작/종료 조건을 처리하는 로직을 개발합니다.
5.  **단어 처리 로직 (최소 검증 및 사용 이력):** 중복 단어 방지 등 최소한의 게임 규칙을 적용합니다.
6.  **(이후) 단어 유효성 검증 강화, API 보안, UI/UX 개선, 배포 순으로 진행합니다.**

# Risks and Mitigations

## Technical challenges
-   **위험:** Gemini API Function Calling의 응답 품질이 기대에 미치지 못하거나, 특정 단어에 대해 부적절한 단어를 생성할 가능성.
    -   **완화:** Prompt 엔지니어링을 통해 AI의 역할과 응답 기준을 명확히 하고, 다양한 테스트 케이스를 통해 Function Calling의 안정성을 검증합니다. 필요시 AI가 제시한 단어에 대한 추가 검증 로직을 클라이언트 또는 서버 사이드에 구현합니다.
-   **위험:** 프론트엔드에서 API 키를 직접 사용할 경우 키 유출 위험.
    -   **완화:** MVP 이후 단계에서 Proxy 서버(Next.js API Routes) 또는 Vercel Edge Function을 도입하여 API 키를 서버 측에서 안전하게 관리하고 호출하도록 변경합니다.
-   **위험:** 단어 유효성 검증을 위한 포괄적인 한국어 단어 리스트 확보의 어려움 또는 외부 사전 API 연동의 복잡성.
    -   **완화:** MVP 단계에서는 단어 유효성 검증을 최소화하거나 생략하고, 이후 단계에서 공개된 한국어 단어 데이터셋을 활용하거나, 안정적인 외부 사전 API를 선정하여 연동합니다.

## Development process
-   **위험:** AI API 연동 및 Function Calling 구현에 예상보다 많은 시간이 소요될 수 있음.
    -   **완화:** Google AI 문서를 충분히 숙지하고, 작은 단위로 기능을 테스트하며 점진적으로 개발합니다. 유사한 예제 프로젝트를 참고합니다.
-   **위험:** 싱글 개발자로 진행 시 특정 기술 문제 해결에 어려움을 겪을 수 있음.
    -   **완화:** 관련 커뮤니티(Next.js, Gemini API)를 적극 활용하고, 문제 발생 시 명확한 질문을 통해 도움을 요청합니다.

# Appendix

## Google Gemini API - Function Calling 상세

- **참고 문서:** [Google Gemini API Docs - Function Calling](https://ai.google.dev/gemini-api/docs/function-calling?hl=ko&example=weather#step_3_execute_set_light_values_function_code)

### Function 정의 예시 (get_next_korean_word)
```json
{
  "name": "get_next_korean_word",
  "description": "끝말잇기 규칙에 맞는 다음 한국어 단어를 제안합니다. 제시된 단어의 마지막 글자로 시작해야 하며, 한국어 명사여야 합니다.",
  "parameters": {
    "type": "object",
    "properties": {
      "last_word": {
        "type": "string",
        "description": "마지막으로 사용된 단어. 이 단어의 마지막 글자로 시작하는 새로운 단어를 찾아야 합니다."
      },
      "used_words": {
        "type": "array",
        "items": {
          "type": "string"
        },
        "description": "이번 게임에서 이미 사용된 단어들의 목록. 여기에 포함된 단어는 다시 사용할 수 없습니다."
      }
    },
    "required": ["last_word", "used_words"]
  }
}
```

### Prompt 예시 (Gemini API 요청 시 함께 사용)
```txt
너는 한국어 끝말잇기 게임의 AI 심판이자 상대 선수이다.
사용자가 단어를 제시하면, 그 단어의 마지막 글자로 시작하는 아직 사용되지 않은 적절한 한국어 명사 단어를 찾아 "get_next_korean_word" 함수를 호출하여 반환해야 한다.
만약 적절한 단어를 찾을 수 없다면, 함수 호출 없이 그 이유를 설명하는 메시지를 반환할 수 있다.

마지막 단어: {last_word}
이미 사용된 단어들: {used_words_list}
```
